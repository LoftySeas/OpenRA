# AI Explainable Decision System

## Goal
Allow developers and players to understand AI decisions.

## Decision Record

Every strategic action should produce:

```
Action:
ATTACK
Target:
North expansion
Confidence:
0.82
Reasons:
- enemy army weaker
- economy advantage
- technology completed
```

## Debug Visualization

Recommended overlays:

- threat heat map
- predicted enemy locations
- target priority
- confidence value
- current strategic goal

## Benefits

- easier debugging
- easier balance tuning
- better player experience
- prevents hidden cheating behavior
