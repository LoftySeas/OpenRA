# AI Bot Personality System

## Objective
Create different RTS opponents without cheating.

## Personality Dimensions

- aggression
- expansion tendency
- technology preference
- risk tolerance
- scouting frequency
- defensive preference

## Examples

Rush:

- fast attack timing
- low economy reserve
- high military production

Turtle:

- defensive buildings
- delayed attack
- technology focus

Economic:

- expansion priority
- resource optimization

## Implementation

Use MAP-Elites or parameter evolution to preserve different strategic styles.

Personality should modify decision preferences, not bypass game rules.
