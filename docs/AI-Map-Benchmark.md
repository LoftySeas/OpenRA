# AI Map Benchmark

## Purpose

Create repeatable scenarios for AI evaluation.

## Categories

Economy:
- Resource rich
- Resource poor
- Expansion focused

Combat:
- Open field
- Choke point
- Multi front

Strategy:
- Rush defense
- Turtle breaking
- Naval control

## Evaluation

Each model should run:
- Multiple maps
- Multiple seeds
- Spawn swaps
- Multiple opponents

Record:
- Win rate
- Game duration
- Resource efficiency
- Strategy diversity
