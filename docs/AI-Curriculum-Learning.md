# AI Curriculum Learning

## Purpose

RTS AI should not start from full-game self play. Training should gradually increase difficulty.

## Stages

### Stage 1: Basic Economy

Learn:

- harvesting
- production balance
- power management

### Stage 2: Military Decisions

Learn:

- army composition
- timing attacks
- defense decisions

### Stage 3: Full Match

Enable:

- fog of war
- expansion
- multiple strategies

## Benefits

Curriculum learning reduces sparse reward problems and allows personal hardware to train useful models.
