# AI Auto Tuning System

## Purpose
Automatically optimize AI parameters and models.

## Search Methods

- CMA-ES
- Bayesian Optimization
- Evolution Strategies
- Grid Search for small spaces

## Tunable Parameters

Economy:
- expansion timing
- worker count
- reserve resources

Military:
- unit ratios
- attack threshold
- defense threshold

Evaluation:
- win rate
- stability
- strategy diversity

The system should preserve different successful strategies rather than only one maximum score model.
