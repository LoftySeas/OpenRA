# AI Developer Setup

## Required
- .NET SDK for OpenRA.
- Python training environment.
- CUDA capable GPU for experiments.
- ONNX Runtime for inference.

## Workflow
1. Build OpenRA.
2. Run headless simulations.
3. Export state data.
4. Train models.
5. Import checkpoints.
6. Validate matches.

## Debugging
Use deterministic seeds, replay files and experiment logs.
